# مدير شبكة واي فاي تجارية (MikroTik)

برنامج ويندوز يتصل بالراوتر عبر RouterOS API لإدارة بيع الإنترنت بالكروت (بالساعة).

## المميزات
- توليد كروت بباقات (ساعة / 3 ساعات / يوم ... وتعديلها) وإنشاؤها مباشرة في الهوتسبوت.
- طباعة الكروت (صفحة HTML جاهزة للطباعة).
- متابعة المتصلين الآن وفصل أي مشترك.
- تسجيل المبيعات وتقارير يومية/شهرية.
- الوقت يُحسب عبر `limit-uptime` فقط أثناء الاتصال الفعلي.

## الإعداد
1. جهّز الراوتر بملف `MIKROTIK_SETUP.rsc` (أو `/ip hotspot setup`).
2. ادفع المشروع إلى GitHub، وسيعمل Actions تلقائيًا.
3. حمّل `WifiManagerSetup.exe` من تبويب Actions → Artifacts (أو من Releases عند إنشاء tag مثل `v1.0`).
4. ثبّته، ثم من تبويب "الاتصال" أدخل عنوان الراوتر والمستخدم وكلمة المرور.

## ملاحظات
- يتطلب RouterOS 6.43 أو أحدث.
- البيانات في `%APPDATA%\WifiManager` (خذ نسخة احتياطية من `data.db`).
